A Python paper-trading bot for pump.fun bonding curves: it buys newly created coins once real demand shows, banks half at 1.8x, and exits on take-profit, stop-loss or staleness rules.

## Run it

```sh
PYTHONHASHSEED=0 python3 -P -s main.py
```
